# ⚡ NeoRubi-AI

**Inteligencia Artificial estilo Cyberpunk** creada desde cero con Google Gemini API.

---

## 🌸 Descripción

NeoRubi es una asistente virtual con interfaz suave y moderna estilo cyberpunk pastel.  
Incluye:

- Chat en tiempo real con Gemini
- Reconocimiento de voz
- Análisis de datos
- Interfaz responsive y agradable
- Historial de conversación

---

## 🛠️ Tecnologías usadas

- HTML5
- CSS3 (diseño pastel cyberpunk)
- JavaScript (Vanilla)
- Vite
- Google Gemini API
- Web Speech API (voz)
